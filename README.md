Sales & Revenue Analysis Dashboard

Project Overview

This project focuses on analyzing sales and revenue data using an interactive Power BI dashboard.

Objectives

- Analyze total sales and revenue.
- Track revenue trends over time.
- Identify top-performing products.
- Compare sales across categories and regions.
- Enable interactive data analysis using slicers and filters.

Tools Used

- Microsoft Power BI
- Microsoft Excel / CSV

Key Features

- KPI cards for sales and revenue.
- Revenue trend visualization.
- Top-performing product analysis.
- Category-wise sales analysis.
- Region-wise revenue analysis.
- Interactive slicers and filters.

Project Files

- Power BI dashboard (.pbix)
- Dashboard screenshot
- Project documentation

Outcome

This project helped me understand data visualization, KPI tracking, and interactive business intelligence dashboards.
